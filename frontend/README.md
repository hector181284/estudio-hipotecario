# Frontend: Estudio Hipotecario

Aplicación web basada en **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS** y **shadcn/ui**.

## Experiencias de Usuario
1. **Asistente Conversacional (`/chat`)**: Flujo guiado para solicitantes de hipoteca, con widgets interactivos de simulación en vivo y gráficos de amortización.
2. **Panel de Gestión y Maestros (`/admin`)**: Configuración de políticas de riesgo, histórico del Euríbor y tablas fiscales de ITP/AJD por Comunidad Autónoma.
